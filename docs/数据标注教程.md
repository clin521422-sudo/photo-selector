# 数据标注教程（0 基础版）

> 目标：让 YOLO 认识**你自己的主体**（COCO 认不出的东西，比如甜品、商品、乐器）。
> 你只需要做两件事：**放照片 + 画框**，其余都是一键。

---

## 一、先搞懂 3 个词

| 词 | 什么意思 |
|---|---|
| **数据集** | 一堆照片 + 每张照片的框。可以有很多个（`datasets/` 下每个文件夹一个数据集） |
| **画框（标注）** | 在照片上按住鼠标拖一个矩形，把目标框住，再选它是什么类 |
| **类别** | 你希望模型认识的东西，比如 `person`（人）、`food`（食物） |

---

## 二、整个流程长这样

```
① 建数据集（敲 1 行命令，只做一次）
        ↓
② 把照片拷进 datasets\<名字>\images\train\
        ↓
③ 双击 数据标注.bat   →   画框   →   关窗口
        ↓
④ 双击 整理数据.bat   →   自动转换+划分+体检
        ↓
⑤ 双击 训练模型.bat   →   出模型
        ↓
⑥ 改 config.py 一行   →   双击 跑测试.bat
```

**只有第 ① 步要敲命令**，其余全是双击。

---

## 三、第 ① 步：建数据集

在 `photo-selector` 目录里开一个命令行（或者双击 `启动.bat` 那个窗口关掉也行），执行：

```bat
python tools\init_dataset.py --names "person,food"
```

- `--names` 就是**你要识别的类别**，英文小写、逗号分隔，**顺序就是编号**（person=0, food=1）
- 数据集默认叫 `mydata`；想换名字加 `--name 你的名字`：

```bat
python tools\init_dataset.py --names "person,food" --name mydata
python tools\init_dataset.py --names "cup,book,phone" --name desk   :: 另一个数据集
```

跑完会建出：

```
datasets\mydata\
├── classes.txt      ← 类别表（想改类别就改这里，或重新跑上面的命令）
├── data.yaml        ← 训练配置，不用管
├── images\train\    ← 照片放这里
├── images\val\      ← 自动划分
├── labels\train\    ← 你的框存这里
└── labels\val\
```

> ⚠️ **类别要在开始画框之前定好**。画完之后再改类别，已有的框会对应错乱。

---

## 四、第 ② 步：放照片

把手机照片直接**拷进** `datasets\mydata\images\train\`。

| 想达到 | 每类照片数 |
|---|---|
| 只是跑通流程 | 20 张 |
| 能用的模型 | **100~150 张** |
| 效果稳 | 300 张 |

要求：
- 覆盖不同角度/远近/光线/背景，别全是同一种拍法
- 照片里**没目标**的也放几张（当反例，减少误检）
- 名字无所谓，别重复就行

---

## 五、第 ③ 步：画框（核心操作）

**双击 `数据标注.bat`** →

1. 如果只有一个数据集，直接用；有多个会先让你**选数据集**（输入编号回车）
2. 左边是照片列表，中间是照片

### 画一个框

| 步骤 | 操作 |
|---|---|
| 1 | 按 **`W`**（或点工具栏的方框图标） |
| 2 | 按住鼠标左键**拖**出一个矩形把目标框住 |
| 3 | 松手后弹出**类别列表** → 用方向键选 → 回车 |
| 4 | 按 **`D`** 切下一张 |

### 其它常用键

| 键 | 作用 |
|---|---|
| `D` / `A` | 下一张 / 上一张 |
| `Ctrl+S` | 保存（**已经开了自动保存，一般不用按**） |
| 鼠标滚轮 | 放大缩小（小目标先放大再框） |
| `Ctrl+滚轮` | 快速缩放 |
| `Delete` | 删掉选中的框 |
| 拖框的边缘 | 微调框的大小 |

### 画框 5 条规矩

1. **框要贴紧目标边缘**，别留一大片空白，也别裁掉目标的一部分
2. **有几个目标画几个框**（婚礼照两个人都要框）
3. **画面里没有目标的照片 → 什么都不画**，直接 `D` 下一张（后面会自动生成空标注）
4. **拿不准的别硬画** → 宁可跳过这张
5. 类别选错：点那个框，`Delete` 删掉重画

画完**直接关窗口**，标注自动保存。

> 存下来的是 `.json`（工具的原始格式），**别担心不是 txt** —— 下一步会自动转换成 YOLO 格式。

---

## 六、第 ④ 步：整理数据（双击 `整理数据.bat`）

它会自动做三件事：

1. **把 `.json` 转成 YOLO 的 `.txt`**（训练只认 txt）
2. **划分验证集**：把 20% 照片挪到 `val`（已经分过就不动）
3. **数据体检**，检查：
   - 有没有照片还没画框
   - 坐标有没有超出 0~1
   - 类别编号对不对
   - 每个类有多少个框（太少会提示）

看到这个就成功：

```
READY.  Next: double click the train bat.
```

如果报红字，按它说的修（最常见：还有照片没画框；或者你打的标签不在 `classes.txt` 里）。

---

## 七、第 ⑤ 步：训练（双击 `训练模型.bat`）

```
双击 训练模型.bat --epochs 30
```

- 会先让你选数据集
- 默认从官方 `yolov8n.pt` 开始迁移学习（**转移学习**，小数据集也能出效果）
- **第一次先 `--epochs 30` 验证流程能跑通**
- 训练的机器要求：脚本用的是 `..\yolo` 那个装了 torch 的环境

| 环境 | 30 epochs × 150 张 | 100 epochs |
|---|---|---|
| GPU（你的 RTX 5060） | 3~5 分钟 | 10~20 分钟 |
| 纯 CPU | 20~40 分钟 | 几小时 |

训练完会自动：
- 导出 `models\<数据集名>.onnx`
- 写 `models\<数据集名>.names.txt`（类别名，系统会自动读）

指标曲线在 `runs\train\<数据集名>\` —— **答辩可以截图用**。

---

## 八、第 ⑥ 步：换上你的模型

打开 `config.py`，找到这一行，把文件名改成你训练出来的：

```python
"subject_model_path": "models/yolov8n.onnx",     # 改前
"subject_model_path": "models/mydata.onnx",      # 改后
```

然后双击 `跑测试.bat`。

> 唯一可能报错的是 `tests/test_subject.py` 里断言了 `top_class == "dog"`（原来是 COCO 模型）。
> 把 `"dog"` 改成你的某个类别名即可。

**想换回原模型**：把那一行改回 `models/yolov8n.onnx` 就行，代码不用动。

---

## 九、我想做很多个数据集，怎么搞？

非常简单，每个数据集就是 `datasets/` 下一个文件夹：

```bat
:: 建第 1 个
python tools\init_dataset.py --names "person,food" --name life
:: 建第 2 个
python tools\init_dataset.py --names "cup,book,phone" --name desk
:: 建第 3 个
python tools\init_dataset.py --names "cat,dog" --name pet
```

之后：

- **双击 `数据标注.bat`** → 会列出所有数据集让你选（选过的会记住为"当前数据集"）
- **双击 `整理数据.bat` / `训练模型.bat`** → 默认用当前数据集，也会先让你确认

每个数据集独立训练，产出 `models\life.onnx`、`models\desk.onnx`……

**小提示**：系统同一时间只能用**一个**主体模型（`config.py` 里那一行）。
要支持多套，就在训练完不同数据集后，手动切 `subject_model_path`，
或者做个小开关（比如按 `PHOTO_MODEL` 环境变量选模型）—— 需要的话可以加。

## 十、检查清单

画框前：

- [ ] `classes.txt` 里的类别是我要的，顺序对
- [ ] 照片已经拷进 `images\train\`

画框后：

- [ ] 每张有目标的照片都画了框
- [ ] 没有目标的照片留空（不用管）
- [ ] 标签没打错别字（工具里可以下拉选，别手打）

训练前：

- [ ] `整理数据.bat` 显示 READY
- [ ] 每类框数 ≥ 100（至少 ≥ 30）
- [ ] `val` 里有照片

训练后：

- [ ] `models\<名字>.onnx` 和 `.names.txt` 都在
- [ ] `config.py` 改了 `subject_model_path`
- [ ] `跑测试.bat` 全绿

## 十一、常见问题

**Q：画框好慢，有快捷键吗？**
有：`W` 画框、`D` 下一张、`Ctrl+S` 保存、滚轮缩放。
另外一个技巧：**同一类连续画**（工具会记住上次的类别），比每张都选类别快很多。

**Q：标签打错了/不在 classes.txt 里怎么办？**
`整理数据.bat` 会告诉你哪些标签没被识别、各多少个。改成 `classes.txt` 里已有的名字重新画，
或把新标签加进 `classes.txt`（**追加到末尾**，不要插在中间，否则编号会乱）。

**Q：必须画完所有照片吗？**
不用。没画的照片在体检时会报"还有 N 张没标注"，训练会被拦下。
要么补画，要么把不需要的照片从 `images\train\` 删掉。

**Q：训练要多久？**
先 `--epochs 30` 跑通，别一上来 100。

**Q：模型效果不好？**
九成是数据问题：每类 <50 张、框画得太松、类别混着标、验证集太小。
先补数据，别急着调参数。

**Q：`数据标注.bat` 打不开 / 闪退？**
把窗口里的报错文字截图发出来。已知一种：提示 `~/.anylabelingrc` 权限问题 —— 本项目的 bat 已自动处理。
