# 1. 核心数据契约

## 1.1 统一返回字典

**所有分析模块**（`modules/*.py` 的 `analyze`）和 **pipeline 汇总** 都遵循这个五键结构，由 `schema.make_result()` 构造。

| 键 | 类型 | 必须 | 含义 | 示例 |
|---|---|---|---|---|
| `module` | `str` | ✅ | 模块名，固定取值见下表 | `"blur"` |
| `score` | `float` | ✅ | 该模块的**原始分数**（各模块量纲不同，见 1.2 表末） | `124.1` |
| `label` | `str` | ✅ | 中文判定标签，取值见第 5 节各模块枚举 | `"清晰"` |
| `passed` | `bool` | ✅ | 是否达到合格阈值 | `True` |
| `details` | `dict` | ✅ | 模块特有细节（至少包含该模块的必填键） | `{"laplacian_var": 124.1, ...}` |

`module` 的合法取值：`"blur"` / `"exposure"` / `"color"` / `"subject"`

> **约束**：五个键**只能有这五个**，多一个少一个测试都会失败（`schema.RESULT_KEYS` 校验）。

## 1.2 details 字段字典

### blur（清晰度）

| 字段 | 类型 | 单位/范围 | 含义 |
|---|---|---|---|
| `laplacian_var` | `float` | ≥ 0 | 拉普拉斯响应方差，越大越清晰（**也是 score**） |
| `threshold` | `float` | ≥ 0 | 本次使用的阈值（来自 config） |
| `fail_reason` | `list[str]` | — | 未通过原因中文短句，通过时为 `[]` |

### exposure（曝光）

| 字段 | 类型 | 单位/范围 | 含义 |
|---|---|---|---|
| `over_ratio` | `float` | 0~1 | **中心加权**后的过曝像素占比（判定用这个） |
| `under_ratio` | `float` | 0~1 | **中心加权**后的欠曝像素占比（判定用这个） |
| `over_ratio_global` | `float` | 0~1 | 全局过曝占比（仅展示，用于对比分区加权的效果） |
| `under_ratio_global` | `float` | 0~1 | 全局欠曝占比（仅展示） |
| `mean_brightness` | `float` | 0~255 | 平均亮度 |
| `dynamic_range` | `float` | 0~255 | P99 - P1 动态范围 |
| `fail_reason` | `list[str]` | — | 未通过原因（含动态范围过小的提示） |

### color（色彩）

| 字段 | 类型 | 单位/范围 | 含义 |
|---|---|---|---|
| `sat_mean` | `float` | 0~255 | HSV 的 S 通道均值（平均饱和度） |
| `contrast` | `float` | ≥ 0 | 灰度图标准差（对比度） |
| `richness` | `float` | 0~1 | H 通道直方图归一化熵（色彩丰富度） |
| `harmony` | `float` | 0~1 | 主色色相的圆形集中度（**仅供参考，不参与判定**） |
| `main_hues` | `list[float]` | 0~179 | K-Means 主色色相（OpenCV 的 H 范围是 0~179，不是 360） |
| `main_weights` | `list[float]` | 0~1，和为 1 | 各主色占比，与 `main_hues` 一一对应 |
| `fail_reason` | `list[str]` | — | 未通过原因 |

### subject（主体）

| 字段 | 类型 | 单位/范围 | 含义 |
|---|---|---|---|
| `max_area_ratio` | `float` | 0~1 | 最大主体框面积 / 整图面积（**score = 该值×100**） |
| `center_offset` | `float` | 0~1 | 主体中心偏移，0=正中，1=贴边 |
| `num_objects` | `int` | ≥ 0 | NMS 后保留的目标数 |
| `top_class` | `str` | — | 最大主体框的类别名（COCO 80 类之一），无目标时 `""` |
| `boxes` | `list[dict]` | — | 检测框列表，按面积降序，最多 `subject_max_objects` 个 |
| `fail_reason` | `list[str]` | — | 未通过原因 |
| `notes` | `list[str]` | — | **提示性信息**（如"主体偏离中心"，不影响 passed） |
| `error` | `str` | — | 仅模型缺失时出现 |

`boxes` 列表里每个元素的结构：

| 字段 | 类型 | 含义 |
|---|---|---|
| `xyxy` | `list[float]` 长度 4 | 框坐标 `[x1, y1, x2, y2]`，**已映射回原图（pipeline 缩放后的图）坐标** |
| `conf` | `float` | 置信度 0~1（保留 3 位小数） |
| `cls_id` | `int` | COCO 类别索引 0~79 |
| `cls_name` | `str` | COCO 类别名，如 `"dog"` |

### 各模块 score 的量纲对照

| 模块 | score 含义 | 典型范围 | 越大越好？ |
|---|---|---|---|
| blur | 拉普拉斯方差原始值 | 0 ~ 数百 | ✅ |
| exposure | 曝光合格度 = `100×(1-over-under)` | 0 ~ 100 | ✅ |
| color | 色彩综合分 = `100×(0.4·饱和 + 0.35·对比 + 0.25·丰富度)` | 0 ~ 100 | ✅ |
| subject | `max_area_ratio × 100` | 0 ~ 100 | ✅ |

## 1.3 完整结果结构

`pipeline.analyze_image()` 返回：

```python
{
  "modules": {                       # 四个模块的统一返回字典
      "blur": {...}, "exposure": {...}, "color": {...}, "subject": {...}
  },
  "overall": {                       # 汇总
      "pass_ratio": 0.75,            # float  通过率 0~1
      "num_passed": 3,               # int    通过项数
      "num_modules": 4,              # int    总项数
      "suggestion": "建议复核",       # str    建议保留 / 建议复核 / 建议淘汰
      "failed_modules": ["exposure"] # list[str] 未通过的模块名
  },
  "image": np.ndarray,               # 统一缩放后的 BGR 图（UI 画框用，坐标与 boxes 一致）
  "meta": {
      "origin_size": (1280, 720),    # tuple[int,int] 原始尺寸 (宽, 高)
      "proc_size": (1024, 576),      # tuple[int,int] 分析尺寸 (宽, 高)
      "resized": True,               # bool  是否发生了缩放
      "elapsed_ms": 105.3            # float 全链路耗时（毫秒）
  }
}
```

## 1.4 错误态约定

| 情况 | 表现 |
|---|---|
| 单个模块内部抛异常 | 该模块返回 `make_result(name, 0.0, "分析失败", False, {"error": "...", "fail_reason": ["模块内部异常"]})`，**其他模块照常** |
| 图片无法解码 | `utils.load_image()` 抛 `ValueError`，由 `app.py` 捕获并提示"图片分析失败" |
| YOLO 模型文件缺失 | subject 返回 `label="模型缺失"`、`passed=False`、`details["error"]` 含路径 |
| 未检测到任何目标 | **不报错**，正常返回 `label="未检测到主体"`、`num_objects=0` |

## 3.2 DEFAULT_CONFIG 全部键

### 图像预处理

| 键 | 类型 | 默认 | 单位 | 含义 |
|---|---|---|---|---|
| `target_long_side` | `int` | `1024` | 像素 | 统一缩放的长边；只缩不放、保留宽高比 |

### 清晰度

| 键 | 类型 | 默认 | 范围 | 含义 | 调大 | 调小 |
|---|---|---|---|---|---|---|
| `blur_threshold` | `float` | `40.0` | ≥0 | 拉普拉斯方差 ≥ 该值视为清晰 | 更严格（更多图被判模糊） | 更宽松 |

> 默认 40 是本项目样图实测校准结果（清晰 51~124，模糊 2.8）。网上经验值 100 会把平滑人像误判成模糊。

### 曝光

| 键 | 类型 | 默认 | 含义 | 备注 |
|---|---|---|---|---|
| `exposure_over_thr` | `int` | `245` | 灰度 ≥ 该值算高光溢出 | 像素级阈值 |
| `exposure_under_thr` | `int` | `10` | 灰度 ≤ 该值算暗部死黑 | 像素级阈值 |
| `exposure_over_max` | `float` | `0.05` | 过曝比例上限（5%） | **参与判定** |
| `exposure_under_max` | `float` | `0.05` | 欠曝比例上限（5%） | **参与判定** |
| `exposure_mean_min` | `float` | `60` | 平均亮度下限 | **参与判定** |
| `exposure_mean_max` | `float` | `190` | 平均亮度上限 | **参与判定** |
| `exposure_dynamic_range_min` | `float` | `80` | P99-P1 下限 | ⚠️ **只进 `fail_reason` 提示，不影响 passed** |

### 色彩

| 键 | 类型 | 默认 | 含义 | 参与判定 |
|---|---|---|---|---|
| `color_sat_min` | `float` | `40.0` | 平均饱和度下限（0~255） | ✅ |
| `color_contrast_min` | `float` | `30.0` | 灰度标准差下限 | ✅ |
| `color_richness_min` | `float` | `0.35` | 色彩丰富度下限 | ✅ |
| `color_richness_max` | `float` | `0.95` | 色彩丰富度上限（太高=杂乱） | ✅ |
| `color_kmeans_k` | `int` | `4` | 主色个数 | ❌（只影响展示） |

### 主体

| 键 | 类型 | 默认 | 含义 | 参与判定 |
|---|---|---|---|---|
| `subject_model_path` | `str` | `"models/yolov8n.onnx"` | 模型路径（相对项目根） | — |
| `subject_conf_threshold` | `float` | `0.25` | 检测置信度阈值 | 间接（决定有没有目标） |
| `subject_iou_threshold` | `float` | `0.45` | NMS IoU 阈值 | 间接 |
| `subject_min_area_ratio` | `float` | `0.05` | 最大主体面积占比下限 | ✅ |
| `subject_max_center_offset` | `float` | `0.35` | 中心偏移上限 | ⚠️ 只作 `notes` 提示 |
| `subject_input_size` | `int` | `640` | 模型输入边长 | — |
| `subject_max_objects` | `int` | `20` | 最多保留检测框数 | — |

# 5. modules（四个分析模块）

四个模块的签名**完全一致**：

```python
def analyze(image: np.ndarray, config: dict) -> dict
```

- `image`：BGR 三通道，**已被 pipeline 缩放到长边 ≤ `target_long_side`**，模块内禁止再整体 resize
- `config`：`DEFAULT_CONFIG` 合并后的字典，所有阈值通过 `config.get(键, 默认值)` 读
- 返回：1.1 的五键字典

## 5.1 blur — 清晰度

| 项目 | 内容 |
|---|---|
| 读配置 | `blur_threshold` |
| 算法 | 灰度 → `GaussianBlur(3,3)` 降噪 → `Laplacian(CV_64F)` → 取 `.var()` |
| `score` | `laplacian_var`（原始方差） |
| `label` 枚举 | `"清晰"` / `"疑似模糊"` |
| `passed` 条件 | `laplacian_var >= blur_threshold` |
| `details` 必填 | `laplacian_var`、`threshold`、`fail_reason` |

## 5.2 exposure — 曝光

| 项目 | 内容 |
|---|---|
| 读配置 | `exposure_over_thr`、`exposure_under_thr`、`exposure_over_max`、`exposure_under_max`、`exposure_mean_min`、`exposure_mean_max`、`exposure_dynamic_range_min` |
| 算法 | 灰度 → 3×3 分区（权重 `[[1,1,1],[1,2,1],[1,1,1]]` 归一化）统计过曝/欠曝 → 平均亮度 → P99-P1 |
| `score` | `clip(100×(1-over_ratio-under_ratio), 0, 100)` |
| `label` 枚举 | `"曝光正常"` / `"过曝"` / `"欠曝"` / `"曝光异常"` |
| `passed` 条件 | `over_ratio ≤ over_max` **且** `under_ratio ≤ under_max` **且** `mean_min ≤ mean ≤ mean_max` |
| `details` 必填 | `over_ratio`、`under_ratio`、`mean_brightness`、`dynamic_range`（+ 展示用 `*_global`、`fail_reason`） |

## 5.3 color — 色彩

| 项目 | 内容 |
|---|---|
| 读配置 | `color_sat_min`、`color_contrast_min`、`color_richness_min`、`color_richness_max`、`color_kmeans_k` |
| 算法 | HSV 拆分 → S 均值 / 灰度标准差 / H 直方图熵(36 bin 归一化) → 缩略图上 K-Means(H,S) 取主色（`setRNGSeed(42)` + `KMEANS_PP_CENTERS` 保证可复现） |
| `score` | `100×(0.4·饱和得分 + 0.35·对比得分 + 0.25·丰富度得分)` |
| `label` 枚举 | `"色彩正常"` / `"色彩平淡"` / `"色彩杂乱"` |
| `passed` 条件 | `sat ≥ sat_min` **且** `contrast ≥ contrast_min` **且** `rich_min ≤ richness ≤ rich_max` |
| `details` 必填 | `sat_mean`、`contrast`、`richness`、`main_hues`（+ `main_weights`、`harmony`、`fail_reason`） |
| 注意 | OpenCV 的 H 范围是 **0~179**；`harmony` 不参与判定（互补色会被圆形统计误判） |

## 5.4 subject — 主体

| 项目 | 内容 |
|---|---|
| 读配置 | `subject_model_path`、`subject_conf_threshold`、`subject_iou_threshold`、`subject_min_area_ratio`、`subject_max_center_offset`、`subject_input_size`、`subject_max_objects` |
| 算法 | 模型缓存加载（`cv2.dnn.readNetFromONNX`，CPU）→ letterbox 到 640 → `blobFromImage(1/255, swapRB=True)` → forward `(1,4+nc,N)` → 按 conf 过滤 → `cv2.dnn.NMSBoxes` → 坐标用 `scale/pad_left/pad_top` 反算回原图 |
| `score` | `clip(max_area_ratio × 100, 0, 100)` |
| `label` 枚举 | `"主体突出"` / `"主体偏小"` / `"未检测到主体"` / `"模型缺失"` |
| `passed` 条件 | `num_objects > 0` **且** `max_area_ratio ≥ subject_min_area_ratio` |
| `details` 必填 | `max_area_ratio`、`center_offset`、`num_objects`、`boxes`（+ `top_class`、`fail_reason`、`notes`） |
| 辅助函数 | `letterbox(image, new_size=640, color=(114,114,114)) -> (canvas, scale, left, top)` |
| 类别名 | `load_class_names(model_path) -> list[str]`：优先读模型旁的 `同名.names.txt`（自训练模型用这个），否则回退 `COCO_NAMES` |
| 类别表 | `COCO_NAMES`（80 类，索引即 `cls_id`），仅在模型没有 `.names.txt` 时使用 |

| `CATEGORY_DIRS` | `dict[str,str]` | `{"建议保留": "建议保留", "建议复核": "建议复核", "建议淘汰": "建议回避"}`（界面用"淘汰"，文件夹用"回避"更柔和） |
| `MANIFEST_HEADER` | `list[str]` | 16 列，见 7.3 |

## 7.2 函数

| 函数 | 签名 | 返回 | 说明 |
|---|---|---|---|
| `md5_bytes()` | `(data: bytes) -> str` | 32 位十六进制 | 内容哈希，用于去重 |
| `save_photo()` | `(data: bytes, filename: str, row: dict) -> dict` | `{"saved": bool, "deduped": bool, "path": str}`（失败时多一个 `"error"`） | 归档一张图 |
| `stats()` | `() -> dict` | `{"建议保留": 4, "建议复核": 16, "建议淘汰": 1, "总计": 21}` | 各分类当前数量 |

`save_photo` 的 `row` 入参结构（由 app.py 组装）：

| 键 | 类型 | 必须 | 说明 |
|---|---|---|---|
| `name` | `str` | ✅ | 原始文件名 |
| `md5` | `str` | ✅ | `md5_bytes(data)` 结果 |
| `suggestion` | `str` | ✅ | 综合建议，用于决定归档目录 |
| `pass_ratio` | `float` | ✅ | 通过率 |
| `modules` | `dict` | ✅ | 四个模块的结果（写台账用） |
| `fail_text` | `dict[str,str]` | ✅ | `{模块名: 拼接后的未通过原因}` |
| `data` / `result` | — | ❌ | 多余字段会被忽略 |

## 7.3 manifest.csv 列字典

| # | 列名 | 类型 | 说明 |
|---|---|---|---|
| 1 | `时间` | `str` | `YYYY-MM-DD HH:MM:SS` |
| 2 | `原文件名` | `str` | 上传时的文件名 |

# 8. auth.py（访问控制）

## 8.1 常量

| 名称 | 类型 | 值 | 含义 |
|---|---|---|---|
| `PROXY_HEADERS` | `tuple[str,...]` | `x-forwarded-for`、`x-real-ip`、`cf-connecting-ip`、`forwarded`、`x-forwarded-host`、`x-forwarded-proto` | 出现任一即视为"经代理/穿透" |
| `MAX_FAILS` | `int` | `5` | 同一来源 IP 最大失败次数 |
| `FAIL_WINDOW_SEC` | `int` | `300` | 统计窗口（秒） |

## 8.2 函数

| 函数 | 签名 | 返回 | 说明 |
|---|---|---|---|
| `evaluate_access()` | `(direct_ip: str, headers: dict) -> dict` | 见下表 | **纯函数**，可单测；判定是否需要密码 |
| `access_info()` | `() -> dict` | 同上 | 从 Streamlit 上下文取真实 IP/请求头后调用 `evaluate_access`；支持两个调试环境变量 |
| `get_password()` | `() -> str` | 密码 | 转调 `config.get_app_password()` |
| `login_gate()` | `(access: dict) -> None` | 无 | **在 app 最开头调用**：需要密码且未登录时渲染登录框并 `st.stop()` |
| `logout_button()` | `() -> None` | 无 | 侧边栏退出按钮（仅已登录时显示） |
| `reset_fails()` | `(ip: str) -> None` | 无 | 登录成功后清空该 IP 的失败记录 |
| `_recent_fails()` | `(ip: str) -> int` | 次数 | 内部：窗口内的失败次数 |
| `_record_fail()` | `(ip: str) -> None` | 无 | 内部：记录一次失败 |

## 8.3 evaluate_access / access_info 返回结构

| 键 | 类型 | 含义 |
|---|---|---|
| `needs_password` | `bool` | 是否需要密码 |
| `ip` | `str` | 判定用的有效客户端 IP（转发头优先），取不到时 `""` |
| `reason` | `str` | 中文说明，直接显示在侧边栏，如"局域网直连（192.168.1.23）→ 免密码" |
| `proxied` | `bool` | 是否检测到代理转发头 |

判定规则（按优先级）：

| 条件 | `needs_password` | 说明 |
|---|---|---|
| 检测到任一 `PROXY_HEADERS` | `True` | 穿透/反代，一律要密码（伪造头只会更严格） |
| 无转发头 + 无 IP | `False` | 本机/测试环境 |
| 无转发头 + IP 非法（如 `testclient`） | `False` | 测试框架占位值 |
| 无转发头 + 私网 IP（10/172.16-31/192.168/127/::1） | `False` | 局域网直连 |
| 无转发头 + 公网 IP | `True` | 公网直连 |

## 8.4 UI 会话状态

| `st.session_state` 键 | 类型 | 含义 |
|---|---|---|
| `_authed` | `bool` | 公网访问是否已通过密码验证 |

## 9.3 关键行为约定

| 行为 | 说明 |
|---|---|
| 归档触发 | 每次运行（含拖滑块导致的 rerun）都会调 `save_photo`，靠 **MD5 去重**保证不重复落盘 |
| 假数据模式 | 打开后 `analyze_image(..., fake=True)` **且跳过归档** |
| 上传上限 | 20 MB/张（`.streamlit/config.toml`），超限 Streamlit 直接拒绝 |
| 中文路径 | 全部走 `utils.load_image`，避免 `cv2.imread` 中文路径失败 |

# 12. 命名与约定

## 12.1 配置键命名

```
<模块名>_<指标>_<min|max|threshold>
```

例：`blur_threshold`、`exposure_over_max`、`color_richness_min`、`subject_min_area_ratio`

## 12.2 模块 `label` 枚举总表

| 模块 | 通过的 label | 未通过的 label | 异常 label |
|---|---|---|---|
| blur | `清晰` | `疑似模糊` | `分析失败` |
| exposure | `曝光正常` | `过曝` / `欠曝` / `曝光异常` | `分析失败` |
| color | `色彩正常` | `色彩平淡` / `色彩杂乱` | `分析失败` |
| subject | `主体突出` | `主体偏小` / `未检测到主体` | `模型缺失` / `分析失败` |

## 12.3 综合建议枚举

`建议保留` / `建议复核` / `建议淘汰`（对应归档目录 `建议保留` / `建议复核` / **`建议回避`**）
