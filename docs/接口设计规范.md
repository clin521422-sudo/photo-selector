# 照片选片系统 · 模块接口设计规范（Skill v1.0）

> 本文件是所有分析模块的唯一接口契约。
> **任何模块开发者（以及你用的 AI 助手）必须先完整读完本文件，再开始写代码。**
> 违反契约的模块不予集成。直接把本文件整段发给组员的 AI 即可。

---

## 0. 一句话总则

**输入一张 BGR 图 + 一个 config 字典，输出一个固定五键的字典。**

模块之间零 import，模块内禁止硬编码阈值，禁止写 UI，禁止整体 resize。

---

## 1. 统一接口签名（一字不差）

```python
def analyze(image: np.ndarray, config: dict) -> dict:
    ...
```

- 文件位置：`modules/<模块名>.py`
- 函数名：必须是 `analyze`
- `image`：**BGR 三通道** `numpy.ndarray`（OpenCV 默认顺序），
  已由 pipeline 统一缩放到**长边 ≤ 1024**，模块内**不得再次整体 resize**
- `config`：字典，所有阈值从这里取，写法 `config.get("key", 默认值)`

---

## 2. 返回格式（必须用 `make_result` 构造）

```python
from schema import make_result

return make_result(
    module="blur",                    # 你的模块名，必填
    score=124.1,                      # float，原始分数
    label="清晰",                      # str，中文标签
    passed=True,                      # bool，是否合格
    details={"laplacian_var": 124.1}, # dict，模块特有细节
)
```

返回字典**必须且只能**包含这五个键：`module` / `score` / `label` / `passed` / `details`。
少一个键、多一个键、类型不对，测试会直接失败。

`score` 的约定（便于界面统一展示）：

| 模块 | score 含义 |
|---|---|
| blur | 拉普拉斯方差原始值（越大越清晰） |
| exposure | 曝光合格度 0~100（溢出像素越少越高） |
| color | 色彩综合分 0~100 |
| subject | 最大主体面积占比 × 100 |

---

## 3. `details` 必填键（界面依赖，少一个 UI 就报错）

| 模块 | details 必须包含 |
|---|---|
| blur | `laplacian_var` |
| exposure | `over_ratio`、`under_ratio`、`mean_brightness`、`dynamic_range` |
| color | `sat_mean`、`contrast`、`richness`、`main_hues` |
| subject | `max_area_ratio`、`center_offset`、`num_objects`、`boxes` |

另外两个可选但推荐：

- `fail_reason`: `list[str]`，中文短句，界面会直接展示"为什么没通过"
- `notes`: `list[str]`，提示性信息（不影响通过），例如构图提示

---

## 4. 依赖白名单（只许 import 这些）

✅ 允许：`cv2`、`numpy`、`schema`、`utils`、`config`

❌ 禁止：其他 `modules/*.py`、`pipeline`、`app`、`streamlit`、`torch`、`tensorflow`

YOLO 模块只允许用 `cv2.dnn.readNetFromONNX` 加载 ONNX 模型，**不得引入 PyTorch**。

---

## 5. 硬性禁止清单

- ❌ 在模块内对整张图 `cv2.resize`（letterbox 除外，且只能用于模型输入）
- ❌ 硬编码阈值数字，必须 `config.get("xxx_threshold", 默认值)`
- ❌ 修改 `schema.py` / `pipeline.py` / `config.py`
- ❌ 写任何 UI 代码
- ❌ 读死路径的文件（模型路径从 `config` 取）
- ❌ 在模块顶层做耗时初始化（加载模型要放在 lazy 缓存里）
- ❌ 往 `config.py` 里加自己的阈值却不提前说明（会和组长的配置冲突）

---

## 6. 测试脚本要求（交付门槛）

每个模块必须附带 `tests/test_<模块名>.py`，满足：

1. 能独立运行：`python tests/test_你的模块.py`
2. 至少 2 条**格式断言**（五个键齐全、类型正确、details 必填键存在）
3. 至少 2 条**业务逻辑断言**（如"模糊图分数 < 清晰图分数"）
4. 全部通过时打印 `✅ <模块名> 模块测试通过`

### 测试模板（照抄，改模块名即可）

```python
"""test_xxx.py —— xxx 模块测试"""
import pathlib
import sys

import cv2

sys.path.insert(0, str(pathlib.Path(__file__).resolve().parent))
from _bootstrap import SAMPLES  # 提供项目根目录和 samples 路径

from config import DEFAULT_CONFIG
from modules.xxx import analyze


def check_format(r):
    assert set(r.keys()) == {"module", "score", "label", "passed", "details"}
    assert isinstance(r["score"], float)
    assert isinstance(r["passed"], bool)
    assert isinstance(r["details"], dict)


def run():
    img = cv2.imread(str(SAMPLES / "normal.jpg"))
    assert img is not None, "samples/ 缺测试图片"

    r = analyze(img, DEFAULT_CONFIG)
    check_format(r)

    # 在这里写你的业务逻辑断言，例如：
    # assert r["passed"] is True
    print(f"  分数={r['score']:.1f} -> {r['label']}")
    print("✅ xxx 模块测试通过")


if __name__ == "__main__":
    run()
```

## 7. `config.py` 阈值命名规范

统一格式：`<模块名>_<指标>_<min|max|threshold>`

```python
DEFAULT_CONFIG = {
    "blur_threshold": 40.0,
    "exposure_over_max": 0.05,
    "exposure_under_max": 0.05,
    "exposure_mean_min": 60,
    "exposure_mean_max": 190,
    "color_sat_min": 40.0,
    "color_contrast_min": 30.0,
    "color_richness_min": 0.35,
    "color_richness_max": 0.95,
    "subject_min_area_ratio": 0.05,
    # ...
}
```

新增阈值前先看 `config.py` 里有没有现成的同义项，不要重复定义。

## 8. pipeline 如何调用你（你不需要改它）

```python
try:
    results[name] = fn(image, cfg)
except Exception as e:
    results[name] = make_result(name, 0.0, "分析失败", False, {"error": str(e)})
```

所以你的模块即使抛异常也不会拖垮系统，**但会被记为"分析失败"**。
请尽量自己处理边界情况（空图、纯色图、模型缺失、字段缺失……）。

---

## 9. 常见错误对照表

| 错误现象 | 原因 | 修复 |
|---|---|---|
| `KeyError: 'xxx'` | details 缺界面依赖的键 | 对照第 3 节补齐 |
| 分数每次跑都不一样 | K-Means 未固定初始化 | 用 `cv2.KMEANS_PP_CENTERS` + `cv2.setRNGSeed(42)` |
| 模糊图分数反而更高 | 逻辑写反 / 没转灰度就做拉普拉斯 | 先 `cvtColor` 灰度再 `Laplacian` |
| 集成后报尺寸不匹配 | 模块内自己 resize 了 | 删掉整体 resize，只保留 letterbox |
| YOLO 框位置偏移 | 没把 letterbox 坐标映射回原图 | 用 `scale` 和 `(left, top)` 反算 |
| 阈值改了没生效 | 硬编码了数字 | 全部改成 `config.get()` |
| `ModuleNotFoundError: modules` | 缺 `modules/__init__.py` | 补一个空文件 |
