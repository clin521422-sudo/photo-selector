# 代码地图（Code Map）

> **用途**：想改某个功能时，快速定位到"哪个文件、哪一行、哪个函数"。
> 行号按当前代码标注，改代码后可能偏移几行 —— 用文件名 + 函数名搜索最稳。
>
> 配套文档：`README.md`（总览）、`docs/接口字典.md`（字段定义）、`docs/接口设计规范.md`（写模块的规则）

## 一、三分钟看懂这个工程

```
用户上传照片
    │
    ▼
app.py  ──────────────────── 界面：上传、显示、排序、导出、归档按钮
    │  调 analyze_image()
    ▼
pipeline.py ───────────────── 调度：缩放 → 依次调 4 个模块 → 汇总
    │  ├── modules/blur.py      清晰度
    │  ├── modules/exposure.py  曝光
    │  ├── modules/color.py     色彩
    │  └── modules/subject.py   主体（YOLO）
    │
    ├── utils.py ────────────── 读图 + 统一缩放
    ├── config.py ───────────── 所有阈值
    ├── schema.py ───────────── 返回格式契约
    └── storage.py ──────────── 按评分归档到 received/ + 写 manifest.csv
```

**只有 3 个文件是"骨架"**：`app.py`（界面）、`pipeline.py`（调度）、`schema.py`（契约）。
**只有 4 个文件是"算法"**：`modules/` 下那四个。
其余（config/utils/storage/auth）都是支持性代码。

## 四、加一个新模块（5 步）

假设要加"闭眼检测" `modules/eye.py`：

1. **新建 `modules/eye.py`**，抄 `modules/blur.py` 的骨架，实现：
   ```python
   def analyze(image, config):
       return make_result("eye", 分数, "标签", True/False, {"必填字段": ...})
   ```
2. **`config.py:52`** 的 `DEFAULT_CONFIG` 里加自己的阈值键：`"eye_xxx_threshold": 0.5`
3. **`pipeline.py:24`** 的 `MODULES` 里注册：`"eye": eye.analyze`（记得顶部 import）
4. **`pipeline.py:31`** 的 `FAKE_MODULES` 里加一个假数据版本（可选但推荐）
5. **`app.py:39` 的 `MODULE_TITLES`**（实际在 pipeline.py:39）加中文名 `"eye": "闭眼"`

然后跑 `python tests\run_all.py`，界面会自动多出一个评分卡。
**不需要改** `app.py` 的渲染逻辑 —— 它是按 `modules` 字典遍历的。

## 五、调试地图（出问题先看哪）

| 现象 | 先看这里 | 怎么查 |
|---|---|---|
| 界面报错 | 浏览器页面上的 traceback | 通常是 `app.py` 某次 `st.*` 调用 |
| 某个模块结果是"分析失败" | 该模块文件 | pipeline 捕获的异常信息在 `details["error"]`，界面"原始返回值"tab 里能看到 |
| 分数不对/判定反了 | 对应 `modules/*.py` | 用 `tools/calibrate.py` 打印原始指标分布 |
| 照片没归档 | `storage.py:107` `save_photo` | 看侧边栏"已归档"数字；`received/.index.json` 里有没有该 MD5 |
| 手机打不开 | `tools/lan_switch.py status` | 防火墙 → AP 隔离 → IP 变了 |
| 公网打不开 | `tools/public_demo.py --selftest` | 隧道是否 http2、URL 是否被误解析 |
| 登录框没弹/弹了进不去 | `auth.py:57` / `config.py:37` | 跑 `python tools\verify_login.py` |
| 改了阈值没生效 | `config.py` | 检查是不是硬编码在模块里了 |
| 测试失败 | `tests/test_xxx.py` | 单独跑那一个，看断言消息 |
